EXPERIMENTO v9 — Diccionario de features del LGBM final (84 features)
Fecha: 2026-08-02
Script: p01_ensamble_lgbm_ols.py | Modelo: exp_v9_lgbm_final.csv (Kaggle 0.264)

Convenciones:
  C = mes del corte (se predice C+2). prom = promedio de tn de los
  últimos 12 meses del producto. Salvo indicación, todo está
  normalizado por prom (adimensional, escala propia del producto).
  NaN = la ventana no existe para ese producto (LGBM lo maneja nativo).
  TARGET: clase_ratio = tn(C+2) / prom. Predicción = ratio * prom.

-------------------------------------------------------------------
LAGS (24)                                            tn_0 .. tn_23
-------------------------------------------------------------------
Ventas mensuales hacia atrás desde el corte, /prom.
  tn_0  = mes del corte C          tn_12 = mismo mes, año anterior
  tn_1  = C-1 ... tn_11 = C-11     tn_13..tn_23 = 2do año (NaN si no existe)

-------------------------------------------------------------------
RATIOS RECIENTES (6)                                 clip [0, 10]
-------------------------------------------------------------------
  r_0_1       tn_0/tn_1                (momentum mensual)
  r_1_2       tn_1/tn_2
  r_02_34     (tn_0+tn_2)/(tn_3+tn_4)
  r_tri       (tn_0+tn_1+tn_2)/(tn_3+tn_4+tn_5)
  r_sem       suma(tn_0..5)/suma(tn_6..11)
  r_yoy_tri   (tn_0+tn_1+tn_2)/(tn_12+tn_13+tn_14)   interanual

-------------------------------------------------------------------
DIFFS CONSECUTIVOS (8)
